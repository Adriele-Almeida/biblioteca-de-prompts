# Biblioteca de prompts

Template visual de Adriele Almeida.

## Etapa atual

Aguardando aprovação do template. Interface em `index.html`, com fundo preto, cards arredondados e verde-limão. Inclui busca, favoritos, cadastro, edição, visualização integral, exclusão e cópia.

Esta prévia guarda as alterações somente no navegador do dispositivo. A integração com Supabase depende da aprovação do template.

## Prompt inicial

O texto completo enviado pela usuária está incluído no template.

## Publicação

O arquivo é estático e pode ser publicado pelo GitHub Pages, usando a branch `main` e a pasta raiz. Vercel não é necessária.
